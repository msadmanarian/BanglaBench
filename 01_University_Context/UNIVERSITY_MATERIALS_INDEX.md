## Synthesis of Academic Principles for BanglaFactBench

From these indexed materials, six core academic pillars are established for this research:

1. **Rigorous Machine Learning Flow (`CSC 4232`, `ML 06`)**: Every experiment follows a strict lifecycle: formal problem framing $\rightarrow$ clean data collection $\rightarrow$ exploratory analysis $\rightarrow$ leak-free partitioning $\rightarrow$ multi-model benchmarking $\rightarrow$ diagnostic error analysis.
2. **Standardized Evaluation Metrics (`ML 05`)**: Misinformation detection benchmarks must not rely solely on accuracy due to class imbalance; Macro-F1, Precision, Recall, and Confusion Matrices are mandatory.
3. **Statistical Hypothesis Testing (`MAT 3103`)**: Performance differences between baseline models, retrieval augmentations, and adversarial conditions must be validated with confidence intervals and significance tests ($p < 0.05$).
4. **Relational Data Integrity (`Data Base Juena Mam`)**: The claim-level dataset schema must maintain referential integrity across claims, evidence documents, annotator judgments, and adjudicated labels.
5. **Algorithmic Soundness in Perturbation (`Algo LCS`, `CLRS`)**: Adversarial perturbations (typos, transliterations, code-mixing) must be governed by algorithmic distance bounds (Levenshtein / LCS) to preserve semantic intent while testing model robustness.
6. **Ethical Responsibility & Academic Integrity (`EE Lecture 1-8`, `IEEE/ACM Code`)**: Strict prohibition of data/result fabrication, careful handling of public claims without defamation, neutral treatment of sensitive political/health claims, and transparent documentation of limitations.
